## Sobre o projeto

A modelagem de domínio segue a proposta discutida em um material de aula publicado em Gist, e a estrutura geral nasceu de um repositório de exemplo mantido pela mesma autora.

## Rodando o projeto

- Copie o repositório para a sua máquina
- Posicione o terminal na pasta principal
- Dispare a aplicação pela tarefa do wrapper: `./gradlew bootrun`


## Rodando os testes

Os testes foram executados numa IDE gratuita de comunidade, sem plugin adicional.
